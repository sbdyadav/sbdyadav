### The analytics came first

Before product, I spent a year on machine learning and analytics. The repos
below are that apprenticeship, kept public because the habit stuck.

It isn't decoration. The Udaan finding was two years of shipment records and a
hypothesis: aggregate return metrics sat inside an "acceptable range" for
months, and only a per-shipment cut showed the pattern.

- **[Data Science Portfolio](https://github.com/sbdyadav/Data_Science_Portfolio)**: EDA, predictive modelling and optimisation across a few industry use cases
- **[Retail demand prediction](https://github.com/sbdyadav/Retail_demand_predicton)**: forecasting, the same problem I later automated across 33 outlets at EatClub
- **[Big Mart sales prediction](https://github.com/sbdyadav/Big_Mart_sales_-prediction_model)**: feature engineering and model iteration on a public retail dataset

SQL, Python, Power BI and Tableau are still how I check whether a story is true
before I tell it. **[PM-Portfolio](https://github.com/sbdyadav/PM-Portfolio)**
is the Next.js source for the site.
